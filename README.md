# Iloshe Properties & Investment Ltd

A modern, responsive real estate web application built for **Iloshe Properties & Investment Ltd**. This website helps users explore verified land and estate investments, book site inspections, read property guides, and contact real estate advisors.

---

## 🚀 Features

- **Hero Banner & Brand Showcase**: Highlighting core offerings with clear calls-to-action.
- **Featured Estates Catalog**: Browse available plots and property details with interactive modals.
- **Site Inspection Booking**: Easy-to-use modal for scheduling physical site visits.
- **Real Estate Guides & Insights**: Helpful articles to guide first-time buyers and seasoned investors.
- **WhatsApp Integration**: Quick contact widget for direct customer support.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

## 💻 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (version 18 or higher recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Faweezee/iloshe-antigravity.git
   cd iloshe-antigravity
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## 📦 Available Scripts
